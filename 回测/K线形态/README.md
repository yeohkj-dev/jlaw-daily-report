# K线形态回测（43 + 28 种形态 + 经典图形，20 年）

用约 2,250 只美股的日线，检验常见K线形态与量价形态到底有没有用。2026-11-06 先用 5 年数据做，**2026-11-07 改用 20 年数据（2005-10-18 → 2026-10-09，含 2008、2020、2022 三次大跌）重做**。
结果也写进了用户本机的 `K线形态大全.html` 和 `交易系统总结.html`。

> **20 年的结论跟 5 年不一样**：5 年版评为「有效」的形态，放到 20 年一个都不过关。短期回测找到的规律，换个年代很容易消失。

## 先看懂这里的 %（用「每笔买 $10,000」来想）
- **20 天超额 / 60 天超额**：信号出现后第二天开盘买，拿 20（或 60）个交易日，这只股票的涨跌 % **减去同一天全部股票的平均涨跌 %**。
  例：+1.24 = 平均比「随便买一只股票」多赚 1.24%，每 $10,000 多赚约 $124。负数 = 比随便买还差。看跌形态反过来算：+ 号表示股票真的跑输了（说对了）。
- **大盘熊市时 60 天**：只看 SPY 收盘在 200 天线下那段时间出现的信号。
- **年份方向正确**：每年分开算，有几年超额方向是对的。
- 下面「进场 / 止损 / 离场」那一节比的是 **同期买 SPY**（不是全部股票平均）。

## 方法
- 样本：约 2,250 只美股（今天市值 ≥3 亿、日成交额 ≥1,000 万美元），信号日 2005-10-18 → 2026-10-09，共 3,383,435 次信号；当天收盘价 ≥$5、20 日均成交额 ≥500 万美元才算。
- 入场：信号隔天开盘；出场：之后第 5 / 10 / 20 / 60 个交易日收盘。**超额** = 形态收益 − 同一信号日全样本平均收益。
- 收益截断在 ±50%（60 天 ±80%），截断造成的基准偏差已扣除（`bias20.json`）。「大盘熊市」= SPY 收盘在 200 天线下。
- **评级**：有效 = 20 天超额 ≥0.25、60 天 ≥0.4、t ≥2、**至少 70% 的年份**方向正确；反向 = 跟教科书相反且 70% 以上年份都相反；其余 = 噪音。（5 年版用「≥4/5 年」，等于 80%。）
- 限制：幸存者偏差（只用今天还在交易的股票，跌到退市的不在样本里，年份越长越严重）；价格不含股息；t 值因持有期重叠偏高。

## 运行
```
python 回测/download20.py                                   # 回测/cache20：2005 起日线（同一个股票池，约 3 分钟）
cd 回测/K线形态 && bash run20.sh                            # BT_TAG=20：形态 4 批 + 基准 + 暴跌研究（约 30 分钟，需约 3GB 内存）
BT_TAG=20 python exit_bt.py                                 # 进场 / 止损 / 离场逐笔（约 1 分钟）
```
不设 `BT_TAG` 就是原来的 5 年版（`回测/cache`，输出文件名不带 20）。

## 主要结论（20 年）
1. **没有一个形态过「有效」**。最接近的：200MA 下 RSI(2)>95 看跌（60 天 +0.78，15/22 年对）、三只乌鸦（60 天 +1.19）、低位放量长下影（60 天 +0.68，大盘熊市时 +1.63）。
2. 单根 / 经典看涨反转形态（吞没、锤子、孕线、平底、刺透）都在 ±0.2% 以内，是噪音。
3. 大盘熊市时，买突破、回踩、内包线 60 天都落后全市场约 1–1.5%（放量突破 -1.09、回踩 20MA -1.08、内包线 -1.45）；高位看跌K线在熊市较准（看跌关键反转 +1.00）。
4. 顺势 + 放量才有一点：个股升势 + 大盘牛市 + 量 ≥1.5 倍时，光头光脚大阳线 60 天 +1.08、向上跳空 +0.64、放量突破 +0.52。
5. 70 种有方向的形态里有 67 种「等确认K线」后 60 天收益更差。
6. 暴跌：个股 5 天跌 >30% 且之前在上升趋势（1,014 次）→ 60 天中位数 +4.8%、上涨率 56.3%；之前在下跌趋势（2,251 次）→ +24.0%（跌到退市的不在样本里，反弹被高估）。5 年版的「前领涨股暴跌后 60 天中位数 −2.5%」在 20 年不成立。

`tools/market_regime.py` 的 `bt_note()` 用这些结论在大盘报告显示「K线形态回测提示」（固定文字，重跑回测后要人工同步）。
`量化/combined.py` 的 `BULL` / `BEAR` 名单仍是 5 年版的「有效」形态，要不要改由用户决定。

## 进场 / 止损 / 离场回测（`exit_bt.py`，BT_TAG=20 → `exit_bt20.json`）
逐笔模拟：信号**第二天开盘买**，止损和卖出按当天真实的高 / 低 / 收盘价成交（跳空到止损下面按开盘价算），同一只股票持仓期间不重复买。
**比同期买 SPY 多赚** = 这笔交易的 % − 同一段时间买 SPY 的 %，再平均。没算手续费（每笔约 0.1–0.2%）。

### 账户回测
把规则放进有资金、仓位上限、手续费的账户（`system_bt.py`，在用户本机）跑：两段（2005–2015、2016–2026）都比一直拿 SPY 好的，只有用到「放量突破 + 跌 15% 才卖 + 拿 60 天」的方案（单独做，或加上长下影），但最大回落比 SPY 深。J Law META 回调（`回测/meta_exit.py`）逐笔加 8% 止损时略好于 SPY，放进账户后输给 SPY。详见用户本机 `交易系统总结.html`。
