# K线形态回测（43 种形态）

用 `回测/cache` 的美股日线（`回测/download.py` 下载），检验常见K线形态与量价形态到底有没有用。
2026-11-06 建立；结果也写进了用户本机的 `K线形态大全.html`。

## 方法
- 样本：2,250 只美股（市值 ≥3 亿、日成交额 ≥1,000 万美元），信号日 2022-08-24 → 2026-10-07，共 959,513 次信号。
- 入场：信号隔天开盘；出场：之后第 5 / 10 / 20 / 60 个交易日收盘。
- **超额** = 形态收益 − 同一信号日全样本平均收益（扣掉大盘涨跌）；看跌形态取负号（跑输大盘 = 说对）。
- 收益截断在 ±50%（60 天 ±80%），截断造成的基准偏差（`bias.json`，60 天约 −0.37%）已扣除。
- 「大盘熊市」= SPY 收盘在 200 天线下。形态定义见 `patterns.py`（都带前置趋势条件）。
- 有幸存者偏差（只用今天仍在交易的股票）；t 值因持有期重叠偏高，只作参考。

## 运行
```
python 回测/download.py            # 先准备 回测/cache（约 2,250 只，5 年）
python 回测/K线形态/backtest.py     # 约 5 分钟 → events.pkl、baseline.pkl（不进仓库）
python 回测/K线形态/bias.py         # 截断偏差
python 回测/K线形态/stats.py        # → stats.json
python 回测/K线形态/cond_base.py    # 只看位置/趋势的条件基准 → cond_base.csv

```

## 主要结论
1. 单根 / 经典看涨反转形态（吞没、锤子、孕线、平底、刺透）基本是噪音。
2. 看跌形态整体比看涨形态可靠；大盘熊市时看跌形态 60 天优势约 +2%。
3. 大盘熊市时，买突破、回踩、内包线 / NR7，60 天落后全市场约 3–4%。
4. 43 种形态里有 40 种「等确认K线」后 60 天收益更差。
5. 暴跌：个股 5 天跌 >30% 且之前在上升趋势（451 次）→ 60 天中位数 -2.5%、上涨率 47.9%；之前在下跌趋势（364 次）→ +13.6%。QQQ 单日跌 ≥5%（1999 起 57 次）→ 20 天中位数 +3.7%、60 天 +0.4%（上涨率 50.9%）。

`tools/market_regime.py` 的 `bt_note()` 用这些结论在大盘报告里显示「K线形态回测提示」，数字更新回测后要同步改。

## 数据挖掘（`mine_feats.py` + `mine.py` → `mine.json`）
每根K线拆成 10 个离散特征（收盘在当日波幅的位置、波幅/ATR、量比、当日涨跌、跳空、相对 50/200MA、距 52 周高点、前 20 天涨跌、连涨连跌、SPY 环境），穷举 1–3 个特征的组合。
**2022-08 → 2024-12 找规律，2025-01 → 2026-10 验证**：两段同方向（样本内 ≥0.6%、样本外 ≥0.4%）、样本内 ≥1,500 次、样本外 ≥600 次、分散在 ≥12 个月份才算通过，共 222 个组合通过，归纳为：
